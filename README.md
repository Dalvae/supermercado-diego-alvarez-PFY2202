# Supermercado Belen (PFY2202)

Inventario del supermercado en React, semanas 1 a 3 de Desarrollo Frontend II. Hecho con Vite, React Router y Tailwind.

Publicado en https://dalvae.github.io/supermercado-diego-alvarez-PFY2202/

Para correrlo en local:

```
npm install
npm run dev
```

`npm run deploy` lo sube a GitHub Pages.
